01 Visão Geral & Stack Tecnológica
Angular Standalone v18+

Arquitetura sem NgModule legados. Componentes, diretivas e pipes autônomos para menor bundle, maior modularidade e carregamento otimizado.

Reatividade & Estado Signals / RxJS

Uso de Angular Signals para estado reativo local e fine-grained reactivity, combinado com RxJS e HttpClient para fluxo de chamadas assíncronas HTTP.

Design System Moderno Vanilla CSS

Interface em Dark Mode com tema customizado, CSS Variables para tokens de design, efeitos de glassmorphism, skeletons de carregamento e animações de micro-interação.

03 Mapeamento de Componentes da Interface
1. Task Dashboard & Stats Header

Exibição centralizada de indicadores reativos (Signals): Total de tarefas, tarefas pendentes e concluídas em tempo real com barra de progresso visual.

2. Task List & Quick Toggle

Listagem fluida com suporte a busca instantânea por título e filtro por status (Todas, Pendentes, Concluídas). Botão direto para alternar o status via endpoint PATCH /tasks/{id}/concluir.

3. Task Form Modal (Criar / Editar)

Formulário reativo com validação de campo obrigatório para título (sincronizado com @NotBlank do Spring), campo opcional para descrição e feedback visual imediato.

4. Toast Notifications & Error Handling

Notificações elegantes para confirmações de sucesso (Ex: "Tarefa criada com sucesso!", "Status atualizado") e alertas de erro HTTP extraídos das exceções personalizadas do Spring Boot.

04 Ajuste Necessário no Backend: Configuração de CORS
⚠️
Atenção para Integração HTTP: O Angular será executado por padrão em http://localhost:4200. Para permitir requisições sem bloqueio de políticas de mesma origem (CORS), o backend Spring Boot precisa liberar as requisições oriundas dessa URL.

Recomendamos adiantar a inclusão da anotação @CrossOrigin no TaskController.java do backend Spring Boot:

@RestController @RequestMapping("/tasks") @CrossOrigin(origins = "http://localhost:4200") // Permite a conexão do Angular public class TaskController { // ... métodos da controller ... }
05 Mapeamento Angular HTTP Service & Endpoints REST
Método HTTP Endpoint Backend Método em TaskService (Angular) Descrição e Retorno
GET /tasks getTasks(): Observable<TaskResponseDTO[]> Lista todas as tarefas para popular a Dashboard.
POST /tasks createTask(dto: TaskRequestDTO): Observable<TaskResponseDTO> Cria uma nova tarefa a partir do formulário reativo.
GET /tasks/{id} getTaskById(id: number): Observable<TaskResponseDTO> Carrega os detalhes de uma tarefa específica para edição.
PUT /tasks/{id} updateTask(id: number, dto: TaskRequestDTO) Atualiza título e descrição da tarefa.
PATCH /tasks/{id}/concluir toggleTaskCompletion(id: number) Alterna o status da tarefa entre concluída/pendente.
DELETE /tasks/{id} deleteTask(id: number): Observable<void> Exclui a tarefa cadastrada.
06 Cronograma de Execução Fase a Fase
Fase 1: Setup do Projeto Angular & Configurações Base Fase 1

Criação do projeto usando Angular CLI (ng new task-manager-frontend --standalone), definição dos tokens CSS de tema escuro e criação das variáveis de ambiente (environments/environment.ts).

Fase 2: Modelos de Dados & Camada de Serviços HTTP Fase 2

Criação das interfaces TypeScript (Task, TaskRequestDTO, TaskResponseDTO), implementação do TaskService utilizando HttpClient e configuração do tratamento centralizado de erros.

Fase 3: Layout Base, Topbar & Componente de Estatísticas Fase 3

Desenvolvimento do layout container, header responsivo, cards de estatísticas (Total, Pendentes, Concluídas) alimentados por Angular Signals.

Fase 4: Listagem de Tarefas, Filtros & Conclusão Rápida Fase 4

Implementação do componente de lista/grid de tarefas, inclusão da busca por texto em tempo real, filtros por status e integração com o botão de toggle concluir.

Fase 5: Form Modal com Reactive Forms (Criar & Editar) Fase 5

Construção do modal com formulário reativo, validações dos campos, suporte para criação de novas tarefas e edição de tarefas existentes.

Fase 6: Polimento Visual, CORS & Testes Finais de Integração Fase 6

Ajuste fino da configuração de CORS no Spring Boot backend, inclusão de micro-animações, estados de carregamento (Skeleton loaders) e testes end-to-end de integração HTTP.

07 Comandos para Inicialização Rápida
# 1. Instalar o Angular CLI (caso ainda não tenha instalado) npm install -g @angular/cli # 2. Criar a aplicação Angular Standalone na pasta de projetos ng new task-manager-frontend --standalone --routing --style=css # 3. Navegar para a pasta criada cd task-manager-frontend # 4. Gerar os modelos, serviços e componentes principais ng g service core/services/task ng g interface core/models/task ng g component features/tasks/components/task-dashboard ng g component features/tasks/components/task-list ng g component features/tasks/components/task-form-modal # 5. Executar o servidor de desenvolvimento ng serve
